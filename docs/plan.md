# Plan

## Retrofit Strategy

This Engineering OS is applied as a retrofit, not as a repository reboot.

## Work Order

1. Add repository operating contract and verification baseline.
2. Document domain, invariants, security, testing, and risk memory.
3. Add reusable prompts for future autonomous iterations.
4. Keep the current runtime intact.
5. Validate the new governance layer with real commands.

## Near-Term Focus

- preserve deterministic report generation
- harden AI overlay post-processing
- keep defect editing and deletion safe
- prepare future model replacement without storage breakage
- keep inference concurrency and queue capacity bounded on both runtime boundaries
- grow regression references into an independently human-annotated accuracy set
- keep `npm run audit` warning-free except for explicitly accepted local data
- use Git history and benchmark results as regression evidence before publication
