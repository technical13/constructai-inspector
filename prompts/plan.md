# Plan Prompt

Use this repository in deterministic engineering mode.

- Read `AGENTS.md`, `docs/os-ultra.md`, `docs/invariants.md`, `docs/regression-memory.md`.
- Restate the requested change in repository terms.
- Perform change impact analysis.
- Classify risk as `LOW`, `MED`, or `HIGH`.
- Produce the smallest safe implementation plan.
- Do not propose stack rewrites unless explicitly requested.
